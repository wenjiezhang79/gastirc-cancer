## 二、病理分支

1. **编码器（7 个）：** UNI2-h（1536）、Virchow2（2560）、CONCH v1.5（768）、MUSK（1024）、Prov-GigaPath（只用切块编码器，1536）、CTransPath-CHIEF（768）、ResNet50（对照，1024）。预期前列：CONCH v1.5、Virchow2、UNI2-h。
2. **比较规则（预先规定，只比一次）：** 7 个统一用固定超参数的 ABMIL，在内部训练集上用 Lauren 和 MSI 做 5 折交叉验证初筛 → 前 2–3 个细调 → 另试前两名特征拼接。选定后锁定。MSI 阳性约 100 例，小差异不过度解读。
3. **聚合：** 门控 ABMIL（2–4 个注意力分支 → 2–4 个病理 token，保存注意力用于热图）为主；TransMIL 对照；**均值池化 + 线性**作为简单基线。

## 三、CT 分支

4. **分析体素：** 层厚已确认 5 mm；默认 0.8 × 0.8 × 5 mm（层面内间距待汇总确认）；层面内重采样，z 方向不插值；个别薄层病例多层平均降到 5 mm。
5. **ROI：** 肿瘤 ROI（约 64–96 mm）+ 区域 ROI（约 160 mm，含胃周与淋巴结），各输出 1 个 token；融合层与具体 CT 编码器无关。
6. **编码器候选（v2，冻结提特征）：** 首选 **2.5D**（肿瘤附近若干轴位层用 2D 编码器提取后聚合）；**Merlin**；CT-FM（是否适合 5 mm 待核实）；SuPreM（要求 1.5 mm 各向同性，作为对照）；**影像组学**作为基线；后期再考虑二阶段 nnU-Net 编码器和端到端微调。
7. **比较规则：** 以 OS C-index + Lauren AUC 筛选，cT 分期作为辅助参考，不用 MSI；内部训练集 5 折，选定后锁定。

## 四、CT 标注与分割流程

8. **顺序：** 每中心先试下载 20–30 例 → DICOM 汇总（层厚、间距、期相、卷积核）→ 全量下载、转 NIfTI → 医生标注。**汇总出来前医生先不开始标注。**
9. **中心点（全部病例）：** 标在本流程生成的 `native/<study_id>.nii.gz` 上；用 3D Slicer 标记点或 ITK-SNAP 小团标签，由程序导入，**不手抄坐标**。位置：肿瘤最大截面的中心，胃壁增厚型标在最厚处。另记录**肿瘤可见度**（清楚 / 不确定 / 看不到）和 **Borrmann 分型**。胃充盈由胃分割自动计算。
10. **两阶段分割：**
    - 第一阶段：TotalSegmentator 自动分割全部病例的胃（无需人工标注，单独 Python 环境）；同时用于中心点自动核查和胃充盈计算。
    - 第二阶段：在胃区域外扩 15–20 mm 的范围内用 nnU-Net 分割肿瘤。训练数据为**内部训练集中按 T 分期分层抽取的 200–300 例**在 5 mm 上的人工勾画；其余病例自动分割，**用中心点挑选肿瘤连通域**，医生审核（`mask_source = auto_reviewed`）。
    - 分割结果用于影像组学、以分割为中心的裁剪、作为额外输入通道。

## 五、融合

11. [CLS] + 病理 token + CT token + 模态类型嵌入 → **1–2 层小 Transformer**（维度 128–256，4 头）。
12. **不做切块与 CT 体素之间的细粒度交叉注意力**：活检与 CT 没有空间对应关系，1600 例训练数据也容易让复杂结构过拟合。
13. 缺失模态：可学习占位 token + 掩码；训练时随机丢弃一个模态（概率约 0.3）。
14. 对照：简单拼接、**后期融合**（用折外预测组合两个单模态模型的输出）。融合模型须明显超过最佳单模态和后期融合。

## 六、输出头与损失

15. Lauren：三分类交叉熵（补充：肠型 vs 非肠型）。
16. 标志物：多标签二分类，缺失屏蔽，类别加权。
    - HER2 阳性 = IHC 3+，或 2+ 且 FISH 阳性；2+ 而无 FISH 时按缺失处理。补充：三分类 0 / low / 阳性。
    - MSI、EBV：二分类。PD-L1：CPS ≥ 5 为主，≥ 1、≥ 10 为辅。Claudin18.2：≥ 75%。Ki-67：阈值待定，在配置中设置，暂不启用。
17. 预后：离散时间生存损失为主，Cox 对比；OS 头 + DFS（手术患者）/ PFS（不可切除患者）。**手术与不可切除两类人群各设基线风险，共享风险评分**；人群类型不作为输入特征。
18. 多任务权重：不确定性加权与固定等权重各跑一次再决定；单任务训练作为必做消融。

## 七、训练与验证

19. 先单模态训练，再初始化融合模型；BF16；一卡一实验；**最终模型 = 5 个折模型集成**，不在全量数据上重训。
20. 校准、阈值、KM 截断值全部由内部训练集的折外预测确定，然后冻结。
21. 治疗方式不作为输入；临床变量留到列线图阶段。
22. 外部队列只在定型后运行一次，按中心分别报告；**阳性少的标志物（MSI、EBV）另报外部合并结果**；内部如有不同年份或扫描仪，先做一次按时间的伪外部检验。
23. 标签规则：`post_neoadj` 的分型与标志物标签在主分析中按缺失处理；清单允许可选的单项来源列（如 `her2_source`）；各中心检测方法需登记。

## 十一、v1 实现约定（2026-11-01 确认）

## 十三、v2 实现约定（2026-11-01 确认）

1. **两阶段分割与中心点的分工：** 第一阶段 TotalSegmentator 分割胃（现成模型，无需标注）；第二阶段在胃外扩 20 mm
   （并保证中心点周围 ±48 mm）内用 nnU-Net 分割肿瘤。**主方案的 ROI 中心 = 医生中心点**（胃癌自动检测难度大，
   中心点约 1 分钟一例，可保证每例位置正确）；分割用于影像组学、以分割质心为中心的裁剪（敏感性分析，可检验全自动定位是否可行）、
   中心点核查。自动分割全部经医生审核后才作为 `auto_reviewed` 使用。
2. **nnU-Net 训练数据：** 只用内部训练集的人工勾画（按 cT 分层抽 200–300 例，`21_seg_sample.sh`）；内部测试集与外部中心的勾画不用于训练。
   分割模型只学"肿瘤在哪"、不接触分型与预后标签，因此对其余病例（含测试集与外部队列）做自动分割不构成标签泄漏。
3. **cTNM：** 清单新增结构化列 `ct_t / ct_n / ct_m / ct_stage_source / ajcc_edition`。cTNM **不作为任何模型的输入**，
   只用于：勾画病例分层抽样；CT 编码器筛选的辅助参考（cT3–4 vs cT1–2 AUC，不参与排名）；v4 的多因素 Cox、列线图与分期分层分析。
4. **CT 编码器（冻结提特征）：** 2.5D 用 RadImageNet ResNet50、ImageNet ResNet50、DINOv2 ViT-B/14（中心层 ±3 / ±7 层，相邻 3 层作 RGB）；
   3D 用 CT-FM、Merlin，SuPreM 为对照；影像组学（pyradiomics，bin width 25 HU，L1 线性模型）为基线。
   3D 模型与 RadImageNet 的适配**须在服务器上用 3–5 例与官方示例代码核对**（`--dump-inputs`，余弦相似度 > 0.99）后再全量提取。
5. **编码器比较（预先规定，只比一次）：** CT 单模态多任务模型（预设 screening：Lauren + OS + cT 辅助头，3 个随机种子，其余超参数固定），
   排名指标 = 折外 OS C-index 与 Lauren 宏平均 AUC 的平均，报告与第一名的配对 bootstrap 差值；影像组学基线一起列出。选定后锁定。
6. **CT 特征接口（v2 / v3 共用）：** `work/ct/features/<编码器>/<study_id>.h5`，每个 ROI 角色（tumor / regional）一个 `[n, D]` 数据集；
   CT 单模态模型每个 ROI 聚合为 1 个 token（门控注意力），缺少的 ROI 用可学习占位 token，训练时随机丢弃一个 ROI（0.1）。
7. **外部工具：** TotalSegmentator、nnU-Net、pyradiomics 各用独立环境，主流程通过命令行调用；运行时不联网，缺权重时报错。
   安装包可在联网电脑上准备后传到服务器（`docs/v2_offline_setup.md`）。
8. **v1 代码不修改：** v2 新建通用 token 多任务框架（`gastric_mm/mtl/`），只导入 v1 的输出头、损失、标签构建、生存时间段与评估函数；
   v1 实验指纹不受新增 v2 配置的影响（有测试保证）。

### 4. 模型结构

```
病理切块特征 → 门控 ABMIL（K=2，来自 v1）→ 2 个病理 token ─┐
CT 肿瘤 ROI   → 门控注意力（K=1，来自 v2）→ 1 个 CT token  ─┼→ 各自线性投影到 d_model
CT 区域 ROI   → 门控注意力（K=1，来自 v2）→ 1 个 CT token  ─┘
[CLS] + 4 个 token + 模态类型嵌入（path / ct）+ 槽位嵌入 → 1–2 层 Transformer（4 头，pre-LN）→ CLS → 多任务输出头
```

- 默认 d_model = 128、1 层；256 维与 2 层作为消融。
- 输出头与损失完全复用 v1 / v2：Lauren 三分类、标志物多标签二分类（缺失屏蔽、正样本加权）、离散时间生存
  （手术 / 不可切除各设基线、共享风险评分）、不确定性加权；任务定义来自 `v3.tasks`（默认同 v1）。
- **缺失模态：** 缺失的槽位填可学习占位 token；是否参与注意力见待确认问题 1（草案倾向：用 key_padding_mask 屏蔽）。
  单个 ROI 缺失（如只有区域 ROI）同样逐槽位处理。
- **模态丢弃：** 两种模态都有的训练病例，以 `v3.train.modality_dropout`（默认 0.3）的概率随机丢掉其中一种（各 50%），
  永远不会两种都丢；CT 内部的 ROI 丢弃沿用 v2（0.1）。
- **简单拼接对照：** `v3.model.fusion=concat`，跳过 Transformer，全部 token 拼接后直接进输出头（同一套代码）。
- **保存：** 折外预测（含 `has_path / has_tumor / has_regional`）、CLS 嵌入、CLS 对各 token 的注意力（看模态贡献）、
  病理切块注意力（热图）、CT 各层注意力。

### 5. 训练

- **单模态初始化（CLAUDE.md 6.5 第 15 条"先单模态训练，再初始化融合模型"）：**
  - 融合模型第 k 折、种子 s：病理分支加载 v1 实验（`v3.init.path_exp`）同种子、同折模型的聚合器参数；
    CT 分支加载 v2 实验（`v3.init.ct_exp`）同种子、同折模型的各 ROI 分支参数。对应种子不存在时直接报错（不悄悄换种子）。
  - 加载时核对编码器名与特征维数一致（v1 模型文件里有 `encoders`，v2 模型文件里有 `encoder`、`rois`）。
- **防泄漏检查（必须）：** 读取 v1 / v2 该折的 `case_ids.json`，若其 train 或 inner_val 中出现融合模型第 k 折的留出病例，直接报错。
- **内层验证集（早停）：** 草案：融合的内层验证 = （v1 该折 inner_val ∪ v2 该折 inner_val）∩ 病例池，其余为训练部分。
  说明：一个初始化模型的训练集可能含另一个模型的内层验证病例，早停略偏乐观；**留出折不受影响**，交叉验证结果仍无偏。见待确认问题 4。
- **学习率：** 预训练分支 `v3.train.branch_lr_mult`（默认 0.1），融合层与输出头为全学习率；可选前 `freeze_epochs` 个 epoch 冻结分支。
  "从头训练"（不初始化）作为消融。是否冻结病理分支见待确认问题 2。
- 其余与 v1 / v2 相同：AdamW + 预热 + 余弦退火、BF16、梯度裁剪与累积、内层验证总损失早停（patience 10）、
  5 折 × 种子、两张卡分折并行、实验配置指纹保护。最终模型 = 5 折（× 种子）集成。
- 显存：病理每例最多 2048 个切块（`v1.train.max_tiles` 的同名设置放在 `v3.train`），40GB 单卡足够。

### 6. 对照与消融

| 类别 | 内容 |
|---|---|
| 最佳单模态 | v1 病理实验、v2 CT 实验的折外预测（直接读取，不重训） |
| 后期融合 | 每个任务：两模态折外 logit 平均（不拟合）；另做交叉拟合堆叠（第 k 折的组合系数只用其他折的折外预测拟合；二分类 / 多分类用逻辑回归，生存用风险 z 分数平均或 Cox）。只有一种模态时用该模态的预测。最终评估时用全部折外预测拟合一次后冻结。输出与普通实验相同格式（`outputs/fusion/<名>/oof_predictions.csv`，`experiment.json` 中 kind=late），可直接参与比较 |
| 融合结构 | Transformer vs 简单拼接；1 层 vs 2 层；128 vs 256 维 |
| 训练策略 | 模态丢弃开 / 关；单模态初始化 vs 从头训练；微调 vs 冻结分支；不确定性加权 vs 固定权重 |
| 单任务 | 主分析任务（Lauren、HER2、MSI、EBV、PD-L1 CPS≥5、Claudin18.2、OS）各一个单任务融合模型（必做） |
| 缺失鲁棒性 | 对两种模态都有的病例，在折外预测时分别人为去掉 CT、去掉病理，报告指标下降幅度 |

### 7. 评估与报告

- 交叉验证报告：同 v1 / v2（折外指标 + bootstrap 95% CI、各折均值 ± 标准差、各种子）；**另按模态可用性分层**
  （两种都有 / 只有病理 / 只有 CT）报告。
- **比较（`fusion/compare.py`）：** 可同时列出 `path_mtl`、`ct_mtl`、`fusion` 三个命名空间的实验与后期融合实验；
  在共同病例上计算，配对 bootstrap 差值；同时报告在全部病例上的结果。
- **"融合明显超过"的判定规则须预先规定**（待确认问题 3），写进配置 `v3.compare` 并在报告中注明。
- 阈值、风险截断：由融合模型折外预测确定后冻结（`postprocess.json`）。
- 最终评估（`fusion/predict.py --final`）：登记模型指纹、同一模型同一队列不重复运行；外部队列按中心报告并另报合并结果
  （MSI、EBV 阳性少，合并结果为主要参考）；均按模态可用性分层。最终评估时可以一起评估最终模型与各对照模型。

### 13. 待确认问题（新会话须先与研究者确认）

1. **缺失模态是否让模型"知道缺了"：** 屏蔽（占位 token 不参与注意力，只用实际存在的模态；草案倾向，理由是缺失往往与中心、
   人群有关，模型可能把"缺没缺"当成捷径，到外部中心失效）；还是可见（占位 token 参与注意力）。另一种作为可配置的对照。
2. **病理分支：** 从 v1 初始化后以 0.1 倍学习率微调（草案倾向），还是冻结、直接用 v1 的病理 token？CT 分支同样的问题。
3. **"融合明显超过"的预先判定规则：** 草案：主分析任务（Lauren、HER2、MSI、EBV、PD-L1 CPS≥5、Claudin18.2、OS）主要指标的平均，
   融合减最佳单模态、融合减后期融合，两个配对 bootstrap 差值的 95% CI 下限都 > 0；各任务的差值只作参考。还是按单个任务判定？
4. **内层验证名单：** 草案为 v1 与 v2 内层验证名单的并集（见第 5 小节说明）；或者重新分层抽 15%（更简单，但初始化模型
   见过部分内层验证病例的比例更高）。
5. 默认结构（d_model 128、1 层 Transformer）与模态丢弃概率 0.3 是否同意。
