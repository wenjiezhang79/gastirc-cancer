## 二、病理分支

1. **编码器（7 个）：** UNI2-h（1536）、Virchow2（2560）、CONCH v1.5（768）、MUSK（1024）、Prov-GigaPath（只用切块编码器，1536）、CTransPath-CHIEF（768）、ResNet50（对照，1024）。预期前列：CONCH v1.5、Virchow2、UNI2-h。
2. **比较规则（预先规定，只比一次）：** 7 个统一用固定超参数的 ABMIL，在内部训练集上用 Lauren 和 MSI 做 5 折交叉验证初筛 → 前 2–3 个细调 → 另试前两名特征拼接。选定后锁定。MSI 阳性约 100 例，小差异不过度解读。
3. **聚合：** 门控 ABMIL（2–4 个注意力分支 → 2–4 个病理 token，保存注意力用于热图）为主；TransMIL 对照；**均值池化 + 线性**作为简单基线。

## 三、CT 分支

4. **分析体素：** 层厚已确认 5 mm；默认 0.8 × 0.8 × 5 mm（层面内间距待汇总确认）；层面内重采样，z 方向不插值；个别薄层病例多层平均降到 5 mm。
5. **ROI：** 肿瘤 ROI（约 64–96 mm）+ 区域 ROI（约 160 mm，含胃周与淋巴结），各输出 1 个 token；融合层与具体 CT 编码器无关。
6. **编码器候选（v2，冻结提特征）：** 首选 **2.5D**（肿瘤附近若干轴位层用 2D 编码器提取后聚合）；**Merlin**；CT-FM（是否适合 5 mm 待核实）；SuPreM（要求 1.5 mm 各向同性，作为对照）；**影像组学**作为基线；后期再考虑二阶段 nnU-Net 编码器和端到端微调。
7. **比较规则：** 以 OS C-index + Lauren AUC 筛选，cT 分期作为辅助参考，不用 MSI；内部训练集 5 折，选定后锁定。

## 四、CT 标注与分割流程

8. **顺序：** 每中心先试下载 20–30 例 → DICOM 汇总（层厚、间距、期相、卷积核）→ 全量下载、转 NIfTI → 医生标注。**汇总出来前医生先不开始标注。**
9. **中心点（全部病例）：** 标在本流程生成的 `native/<study_id>.nii.gz` 上；用 3D Slicer 标记点或 ITK-SNAP 小团标签，由程序导入，**不手抄坐标**。位置：肿瘤最大截面的中心，胃壁增厚型标在最厚处。另记录**肿瘤可见度**（清楚 / 不确定 / 看不到）和 **Borrmann 分型**。胃充盈由胃分割自动计算。
10. **两阶段分割：**
    - 第一阶段：TotalSegmentator 自动分割全部病例的胃（无需人工标注，单独 Python 环境）；同时用于中心点自动核查和胃充盈计算。
    - 第二阶段：在胃区域外扩 15–20 mm 的范围内用 nnU-Net 分割肿瘤。训练数据为**内部训练集中按 T 分期分层抽取的 200–300 例**在 5 mm 上的人工勾画；其余病例自动分割，**用中心点挑选肿瘤连通域**，医生审核（`mask_source = auto_reviewed`）。
    - 分割结果用于影像组学、以分割为中心的裁剪、作为额外输入通道。

## 五、融合

11. [CLS] + 病理 token + CT token + 模态类型嵌入 → **1–2 层小 Transformer**（维度 128–256，4 头）。
12. **不做切块与 CT 体素之间的细粒度交叉注意力**：活检与 CT 没有空间对应关系，1600 例训练数据也容易让复杂结构过拟合。
13. 缺失模态：可学习占位 token + 掩码；训练时随机丢弃一个模态（概率约 0.3）。
14. 对照：简单拼接、**后期融合**（用折外预测组合两个单模态模型的输出）。融合模型须明显超过最佳单模态和后期融合。

## 六、输出头与损失

15. Lauren：三分类交叉熵（补充：肠型 vs 非肠型）。
16. 标志物：多标签二分类，缺失屏蔽，类别加权。
    - HER2 阳性 = IHC 3+，或 2+ 且 FISH 阳性；2+ 而无 FISH 时按缺失处理。补充：三分类 0 / low / 阳性。
    - MSI、EBV：二分类。PD-L1：CPS ≥ 5 为主，≥ 1、≥ 10 为辅。Claudin18.2：≥ 75%。Ki-67：阈值待定，在配置中设置，暂不启用。
17. 预后：离散时间生存损失为主，Cox 对比；OS 头 + DFS（手术患者）/ PFS（不可切除患者）。**手术与不可切除两类人群各设基线风险，共享风险评分**；人群类型不作为输入特征。
18. 多任务权重：不确定性加权与固定等权重各跑一次再决定；单任务训练作为必做消融。

## 七、训练与验证

19. 先单模态训练，再初始化融合模型；BF16；一卡一实验；**最终模型 = 5 个折模型集成**，不在全量数据上重训。
20. 校准、阈值、KM 截断值全部由内部训练集的折外预测确定，然后冻结。
21. 治疗方式不作为输入；临床变量留到列线图阶段。
22. 外部队列只在定型后运行一次，按中心分别报告；**阳性少的标志物（MSI、EBV）另报外部合并结果**；内部如有不同年份或扫描仪，先做一次按时间的伪外部检验。
23. 标签规则：`post_neoadj` 的分型与标志物标签在主分析中按缺失处理；清单允许可选的单项来源列（如 `her2_source`）；各中心检测方法需登记。

## 八、数据安全

## 十三、v2 实现约定（2026-11-01 确认）

1. **两阶段分割与中心点的分工：** 第一阶段 TotalSegmentator 分割胃（现成模型，无需标注）；第二阶段在胃外扩 20 mm
   （并保证中心点周围 ±48 mm）内用 nnU-Net 分割肿瘤。**主方案的 ROI 中心 = 医生中心点**（胃癌自动检测难度大，
   中心点约 1 分钟一例，可保证每例位置正确）；分割用于影像组学、以分割质心为中心的裁剪（敏感性分析，可检验全自动定位是否可行）、
   中心点核查。自动分割全部经医生审核后才作为 `auto_reviewed` 使用。
2. **nnU-Net 训练数据：** 只用内部训练集的人工勾画（按 cT 分层抽 200–300 例，`21_seg_sample.sh`）；内部测试集与外部中心的勾画不用于训练。
   分割模型只学"肿瘤在哪"、不接触分型与预后标签，因此对其余病例（含测试集与外部队列）做自动分割不构成标签泄漏。
3. **cTNM：** 清单新增结构化列 `ct_t / ct_n / ct_m / ct_stage_source / ajcc_edition`。cTNM **不作为任何模型的输入**，
   只用于：勾画病例分层抽样；CT 编码器筛选的辅助参考（cT3–4 vs cT1–2 AUC，不参与排名）；v4 的多因素 Cox、列线图与分期分层分析。
4. **CT 编码器（冻结提特征）：** 2.5D 用 RadImageNet ResNet50、ImageNet ResNet50、DINOv2 ViT-B/14（中心层 ±3 / ±7 层，相邻 3 层作 RGB）；
   3D 用 CT-FM、Merlin，SuPreM 为对照；影像组学（pyradiomics，bin width 25 HU，L1 线性模型）为基线。
   3D 模型与 RadImageNet 的适配**须在服务器上用 3–5 例与官方示例代码核对**（`--dump-inputs`，余弦相似度 > 0.99）后再全量提取。
5. **编码器比较（预先规定，只比一次）：** CT 单模态多任务模型（预设 screening：Lauren + OS + cT 辅助头，3 个随机种子，其余超参数固定），
   排名指标 = 折外 OS C-index 与 Lauren 宏平均 AUC 的平均，报告与第一名的配对 bootstrap 差值；影像组学基线一起列出。选定后锁定。
6. **CT 特征接口（v2 / v3 共用）：** `work/ct/features/<编码器>/<study_id>.h5`，每个 ROI 角色（tumor / regional）一个 `[n, D]` 数据集；
   CT 单模态模型每个 ROI 聚合为 1 个 token（门控注意力），缺少的 ROI 用可学习占位 token，训练时随机丢弃一个 ROI（0.1）。
7. **外部工具：** TotalSegmentator、nnU-Net、pyradiomics 各用独立环境，主流程通过命令行调用；运行时不联网，缺权重时报错。
   安装包可在联网电脑上准备后传到服务器（`docs/v2_offline_setup.md`）。
8. **v1 代码不修改：** v2 新建通用 token 多任务框架（`gastric_mm/mtl/`），只导入 v1 的输出头、损失、标签构建、生存时间段与评估函数；
   v1 实验指纹不受新增 v2 配置的影响（有测试保证）。

### 3. 病例池与模态可用性

- 病例池 = 内部训练集中**至少有一种模态特征**的病例；两种都没有的不进模型，报告中列出人数。
- **训练前先做模态可用性检查**（`fusion.check`）：输出逐例清单 `modality_availability.csv`（只含 study_id；
  是否有病理 / 肿瘤 ROI / 区域 ROI，缺失时写出能判断的原因，如清单未填路径、特征文件不存在、可见度 invisible 无中心点），
  以及按中心、人群汇总的缺失比例；某中心缺失比例明显偏高时提示。
- 报告中按"两种都有 / 只有病理 / 只有 CT"列出各折例数。内部测试集与外部队列：训练代码不读取（有测试保证）。

### 4. 模型结构（主模型，预先确定）

```
病理切块特征 → 门控 ABMIL（K=2，来自 v1）→ 2 个病理 token ─┐
CT 肿瘤 ROI   → 门控注意力（K=1，来自 v2）→ 1 个 CT token  ─┼→ 各自线性投影到 d_model
CT 区域 ROI   → 门控注意力（K=1，来自 v2）→ 1 个 CT token  ─┘
[CLS] + 4 个 token + 模态类型嵌入（path / ct）+ 槽位嵌入 → 1 层 Transformer（d_model 128，4 头，pre-LN）→ CLS → 多任务输出头
```

- 输出头与损失完全复用 v1 / v2（Lauren 三分类、标志物多标签二分类、离散时间生存按人群设基线、不确定性加权）；任务定义来自 `v3.tasks`（默认同 v1）。
- **缺失模态：屏蔽**——缺失槽位（含单个 ROI 缺失）不参与注意力（key_padding_mask），CLS 只看实际存在的 token；
  "可见"（占位 token 参与注意力）只作对照。屏蔽模式下 Transformer 中的占位 token 不起作用，只在拼接 / 双线性对照中使用。
- **模态丢弃：** 两种都有的训练病例，以 0.3 的概率随机遮住其中一种（各 50%），永远不会两种都遮；CT 内部 ROI 丢弃沿用 v2（0.1）。
- **保存：** 折外预测（含 `has_path / has_tumor / has_regional`）、CLS 嵌入、CLS 对各 token 的注意力、病理切块注意力、CT 各层注意力。
- **主模型现在即定：** Transformer + 屏蔽 + 单模态初始化后微调 + 模态丢弃 0.3。消融只用于说明和讨论，不用来更换主模型；
  唯一例外是 CLAUDE.md 6.4 第 14 条规定的多任务权重（不确定性加权 vs 固定权重）由内部训练集折外结果决定。

### 5. 训练

- **单模态初始化：** 融合模型第 k 折、种子 s 的病理分支加载 v1 实验（`v3.init.path_exp`）同种子、同折模型的聚合器参数；
  CT 分支加载 v2 实验（`v3.init.ct_exp`）同种子、同折模型的各 ROI 分支参数。对应种子 / 折不存在时直接报错（不悄悄换种子）；
  核对编码器名与特征维数。两个分支规则相同。
- **分支微调：** 分支学习率 = 0.1 × 全学习率（`v3.train.branch_lr_mult`），融合层与输出头全学习率；`freeze_epochs` 默认 0。
- **防泄漏检查（必须）：** v1 / v2 该折 `case_ids.json` 的 train 或 inner_val 中若出现融合第 k 折的留出病例，直接报错。
- **共用内层验证名单（早停）：** 对每个（种子 s, 折 k），在**整个内部训练集**（不看模态）中除第 k 折以外的病例里按 `split.stratify_by`
  分层抽 `split.inner_val_fraction`（15%），保存为 `work/splits/inner_val/split_seed<划分种子>_s<s>.csv`；v1 / v2 / v3 都读这份名单
  （各取自己有特征的部分）。这样融合的内层验证病例两个分支都没见过，且训练人数不减少。已有名单与重新计算结果不一致时报错。
  仍存在的局限：融合的训练病例大多也是分支训练过的（彻底消除需嵌套交叉验证，代价约 5 倍，不做），用"从头训练"消融检查影响大小；
  留出折不受影响，交叉验证结果无偏。
- 其余与 v1 / v2 相同：AdamW + 预热 + 余弦退火、BF16、梯度裁剪与累积、内层验证总损失早停（patience 10）、5 折 × 种子
  （沿用 v1 / v2 最终实验的种子）、两卡分折并行、实验配置指纹保护。最终模型 = 5 折（× 种子）集成。
- 病理每例训练时最多 2048 个切块（`v3.train.max_tiles`），40GB 单卡足够。

### 6. 对照与消融

| 档 | 内容 |
|---|---|
| 必做 | 最佳单模态（v1、v2 折外预测，直接读取）；后期融合（两模态折外 logit 平均；交叉拟合堆叠——第 k 折组合系数只用其他折折外预测拟合，二分类 / 多分类逻辑回归，生存风险 z 分数加权；只有一种模态时用该模态预测）；简单拼接；单任务融合模型（7 个主分析任务各一个，结构与超参数同主模型，不单独调参） |
| 建议 | 初始化后微调 vs **冻结分支** vs **从头训练**；模态丢弃 0 / 0.3 / 0.5；屏蔽 vs 可见；128 vs 256 维；1 层 vs 2 层；不确定性加权 vs 固定权重；预测时人为去掉 CT / 病理（缺失鲁棒性） |
| 新增 | ① 单模态辅助头（病理 token、CT token 各自接输出头算辅助损失，防止模型只依赖病理）；③ 门控双线性融合（Pathomic Fusion 式，文献常用基线）；④ 只用肿瘤 ROI 的 CT；⑤ 模态贡献分析（CLS 对病理 / CT token 的注意力占比，按任务、中心汇总） |

不做切块与 CT 体素之间的交叉注意力（如 MCAT）：活检与 CT 无空间对应，数据量不足（第五节第 12 条）。
默认所有实验用全部种子；脚本可用 `--seeds` 为非必做消融减少种子。

### 7. 评估、报告与预先规定的判定规则

- 交叉验证报告：同 v1 / v2，另按模态可用性分层（两种都有 / 只有病理 / 只有 CT）与按中心报告。
- **比较报告（`fusion/compare.py`）：** 病理单模态、CT 单模态、后期融合、融合及各消融并列，每个任务一行，配对 bootstrap 差值与 95% CI。
- **主结论（预先规定，写入 `v3.compare`）：**
  - 主结论任务（5 个）：Lauren（宏平均 AUC）、HER2、PD-L1 CPS≥5、Claudin18.2（AUC）、OS（C-index）；取这 5 个主要指标的平均。
  - "最佳单模态" = 每个任务分别取病理、CT 中较好者；"后期融合" = 平均与交叉拟合两种中较好者（均从保守出发）。
  - 判定：融合 − 最佳单模态、融合 − 后期融合，两个配对 bootstrap 差值（按病人重抽样 2000 次）的 95% CI 下限都 > 0，才称"明显超过"。
  - 主判定只用两种模态都有的病例（三类模型在每例都有预测），用种子平均后的折外预测；全部病例的结果另报。各任务差值只作参考。
  - **MSI、EBV**（信息几乎只在病理、阳性少）不进主结论平均，照常并列报告；另做**非劣效检查**：融合 − 病理单模态的 AUC 差值
    95% CI 下限 ≥ −0.05 为"没有明显变差"；不通过时如实报告（因 CI 过宽不通过时写"证据不足"），临床上建议用病理模型的预测。
- 阈值、风险截断：由融合模型折外预测确定后冻结（`postprocess.json`）。
- 最终评估（`fusion/predict.py --final`）：登记模型指纹、同一模型同一队列不重复运行；外部队列按中心报告并另报合并结果
  （MSI、EBV 以合并结果为主）；均按模态可用性分层。可一起评估最终模型与各对照模型；禁止看了测试结果再回头修改模型。

### 13. 开发中发现与处理（2026-11-01）

- **现象（假数据，内部 300 例，5 折）：** 冻结从 v1 初始化的病理分支、只训练融合层时，融合模型 MSI AUC 约 0.87，v1 病理模型约 0.98；
  Lauren 也略低于 v1。模态丢弃（0 / 0.3）、分支学习率（0.1 / 1）都不是原因。
- **处理（研究者 2026-11-01 选定方案 A）：** 主模型加入**直通路径**（`v3.model.skip: true`）——输出头同时读取 CLS 与各模态自己的池化 token
  [CLS ; 病理 ; CT]；mask 模式下缺失模态的池化 token 为零向量。`skip: false` 作为消融（`abl_noskip`）。
- **加直通路径后的复查：** 冻结分支时 MSI 0.87 → 0.90，主模型 MSI 0.89 → 0.90，改善有限。进一步排查发现主要原因是**早停时机**：
  融合模型在第 6–9 个 epoch 达到内层验证总损失最低（v1 为第 15–21 个 epoch），此时 MSI 的验证损失仍在下降；
  延长 patience 不改变结果（恢复的仍是总损失最低的 epoch）。假数据 11 个任务中有 8 个没有信号，融合模型对这些任务过拟合更快，
  总损失提前到达最低点。这是预先规定的"总损失早停"规则在该假数据上的表现，不是程序错误；真实数据上需看实际情况。
- **进一步诊断（研究者要求查清原因，2026-11-01）：** 见 `docs/v3_diagnosis.md`。结论：两个主要原因是多任务早停被无信号任务拉早、
  以及分支 token 在训练病例上"背过答案"；二者都随样本量增大而减弱——假数据内部 1200 例时融合 MSI 0.971 vs v1 0.977、
  Lauren 持平、OS 高于两个单模态。真实数据（每折训练约 1100 例）预计影响较小，用 `36_v3_diagnose.sh` 与非劣效检查核对。
- **不再改动：** 早停规则（CLAUDE.md 6.5 第 15 条）保持不变。真实数据上，MSI / EBV 的非劣效检查与单任务融合模型（必做消融）会直接反映这一问题；
  若届时仍明显，可考虑的备选（须在看外部 / 测试结果之前决定）：按任务分别选最佳 epoch、或减少主模型中无信号的辅助任务。
